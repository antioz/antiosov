# Шрифты для PDF-билета (lib/ticket.js)

Статичные TTF, обрезаны pyftsubset до диапазонов U+0020-007E, U+00A0-00FF, U+0400-04FF, U+2116 (№), U+20BD (₽).

- `CormorantGaramond-Italic.ttf`, `CormorantGaramond-LightItalic.ttf` — Cormorant Garamond (Catharsis Fonts), SIL OFL 1.1.
  Запечены из вариативного `CormorantGaramond-Italic[wght].ttf` (google/fonts) через fontTools varLib.instancer, wght 400 и 300.
- `Lato-Regular.ttf` — Lato (Łukasz Dziedzic), SIL OFL 1.1, статик с google/fonts.
